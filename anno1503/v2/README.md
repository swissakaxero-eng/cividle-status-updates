# Anno 1503 Auto-Update V2

Stable release feed for the side-by-side Anno 1503 trainer updater.

- Complete packages only; no dynamic patch execution.
- A release is activated only after package/hash validation, EXE self-test and GUI heartbeat verification.
- Existing versions stay in separate directories for rollback.
- The live Anno1503.exe process is never terminated by the updater.
- Binary ZIPs may be delivered through the existing OneDrive release folder, while this GitHub feed remains the authority for the approved SHA-256 and metadata.
